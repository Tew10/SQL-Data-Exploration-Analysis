



# SQL Data Analysis Learning

## Overview
This repository contains a set of SQL queries developed for **learning and practicing data analysis using relational databases**.  
The project focuses on applying SQL concepts to real-world scenarios, including data exploration, aggregation, and integration.

---

## Database
The queries are based on a **sample relational database (Northwind model)**, commonly used for educational purposes.

---

## SQL Concepts Practiced
- `SELECT` and `WHERE` clauses  
- `ORDER BY` for sorting  
- `INNER JOIN` for combining tables  
- `GROUP BY` with `HAVING` for aggregated filtering  
- Aggregate functions: `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`  
- Calculations using table columns  
- `UNION` for combining datasets  
- Data type conversion with `CAST`  
- Data standardization across tables  

---

## Queries Included
1. **Exploring Orders** – Basic exploration of the `Orders` table  
2. **Employee Order Analysis** – Counts orders per employee filtered by city and volume  
3. **Order Metrics** – Calculates total, average, minimum, and maximum order values  
4. **Data Integration** – Combines `Customers` and `Suppliers` into a unified view using `UNION`  

---

## Purpose
- Practice SQL for data analysis  
- Understand relational joins and aggregations  
- Simulate real-world analytical scenarios  
- Build a portfolio-ready SQL project  

---

## Notes
- This repository **only contains SQL queries**, not the database itself.  
- All queries are **read-only (`SELECT`)**, designed for learning and experimentation.  
- Compatible with any relational database that supports standard SQL syntax.
